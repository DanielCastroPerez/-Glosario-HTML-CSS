# Glosario de CSS

Proyecto para practicar y documentar propiedades de CSS. La idea es ir armando un glosario visual donde cada entrada muestra cómo se usa una propiedad, con su ejemplo funcionando en vivo.

## 🎯 Objetivo

Crear una página con HTML y CSS puro donde cada propiedad de CSS tenga:

- Su **nombre** y una breve descripción.
- Un ejemplo de código (HTML + CSS, o solo CSS cuando la propiedad no necesite marcado extra).
- Una **demo visual** del resultado, para ver el efecto en tiempo real y no solo leerlo.

## 🧱 Estructura de cada entrada

Cada propiedad se presenta en dos columnas (o una sola cuando aplique):

| Columna izquierda | Columna derecha |
|---|---|
| Código de ejemplo y resultado (HTML) | Código de ejemplo y resultado (CSS) |
